# Simulation code for arXiv:2602.14787 (2026)
This repository contains MATLAB code to reproduce the figures and simulation results presented in the following paper:

L. Ermoneit, A. Thayil, T. Koprucki and M. Kantner:
<i>Exact Multi-Valley Envelope Function Theory of Valley Splitting in Si/SiGe Nanostructures</i>, 
arXiv:2602.14787, DOI: <a href="https://doi.org/10.48550/arXiv.2602.14787">10.48550/arXiv.2602.14787</a>

Simulations were carried out using MATLAB R2023a.
