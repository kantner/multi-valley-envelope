# Simulation code for Phys. Rev. B 113, 245306 (2026)
This repository contains MATLAB code to reproduce the figures and simulation results presented in the following paper:

L. Ermoneit, A. Thayil, T. Koprucki and M. Kantner:
<i>Exact multivalley envelope function theory of valley splitting in Si/SiGe nanostructures</i>, 
Phys. Rev. B 113, 245306 (2026), DOI: <a href="https://doi.org/10.1103/md2x-s44y">10.1103/md2x-s44y</a>

Preprint: <a href="https://doi.org/10.48550/arXiv.2602.14787">arXiv.2602.14787</a>

Simulations were carried out using MATLAB R2023a.
